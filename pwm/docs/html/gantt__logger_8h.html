Detailed Description

Low-Overhead Lock-Free Logger for Gantt Chart generation.

  • This module records thread execution events (START/END) into a circular buffer (Ring Buffer) using atomic operations.
  • Note
    This implementation is "Lock-Free" to ensure that High-Priority Real-Time threads (like SigGen) are NEVER blocked by logging operations.

void gantt_log_event ( uint8_t  thread_id,
gantt_event_type_t  event_type

Logs a thread event (Critical Path).

  • This function is LOCK-FREE and generic. It uses atomic_inc to reserve space in the ring buffer. If the buffer is full, the event is silently dropped to preserve system timing.
  • Parameters
    thread_idID obtained from gantt_register_thread().
    event_typeGANTT_EVENT_START or GANTT_EVENT_END.
