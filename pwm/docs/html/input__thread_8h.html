Detailed Description

Human-Machine Interface (HMI) Handling Module.

  • This module manages the 4 physical buttons on the nRF52840-DK. It uses interrupts and semaphores to react to user input with low latency.

Entry point for the Input Processing Thread.

  • This thread sleeps on a semaphore waiting for GPIO interrupts. When a button is pressed, it wakes up, debounces the signal, updates the RTDB state, and logs the event to the Gantt chart.
