Detailed Description

System Entry Point and Orchestrator.

  • This module is responsible for the system initialization sequence:
  1. Initializes the Real-Time Database (RTDB) [Implicit].
  2. Initializes the Gantt Logger subsystem.
  3. Spawns all worker threads in order of criticality.
  • Note
    Architecture: The system follows a prioritized preemptive scheduling model compliant with Rate Monotonic Scheduling (RMS) principles.

void main ( void  )

Main Application Entry Point.

  • Configures the system and launches the Real-Time Operating System kernel. Never returns.
  • Launches the Critical Signal Generator Thread. Priority: 2 (Highest). Period: 100us (Hard Real-Time).
  • Launches the Input Handling Thread. Priority: 5. Event-driven (Interrupts).
  • Launches the UART Command Parser Thread. Priority: 7. Handles heavy string parsing without blocking SigGen.
  • Launches the LED Update Thread. Priority: 10 (Lowest). Visual feedback is non-critical.
