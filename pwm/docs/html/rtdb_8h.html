Detailed Description

Real-Time Database (RTDB) Module.

  • This module acts as a thread-safe shared memory region. It uses Mutexes to protect read/write operations on the system state, preventing Race Conditions between the High-Priority SigGen thread and the Lower-Priority Command/Input threads.
