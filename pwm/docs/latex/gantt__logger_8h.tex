\doxysubsection{Detailed Description}
Low-\/\+Overhead Lock-\/\+Free Logger for Gantt Chart generation. 


\begin{DoxyItemize}
\item This module records thread execution events (START/\+END) into a circular buffer (Ring Buffer) using atomic operations.
\item \begin{DoxyNote}{Note}
This implementation is \char`\"{}\+Lock-\/\+Free\char`\"{} to ensure that High-\/\+Priority Real-\/\+Time threads (like Sig\+Gen) are NEVER blocked by logging operations. 
\end{DoxyNote}

\end{DoxyItemize}
