Entry point for the Input Processing Thread. 


\begin{DoxyItemize}
\item This thread sleeps on a semaphore waiting for GPIO interrupts. When a button is pressed, it wakes up, debounces the signal, updates the RTDB state, and logs the event to the Gantt chart.
