\doxysubsection{Detailed Description}
Human-\/\+Machine Interface (HMI) Handling Module. 


\begin{DoxyItemize}
\item This module manages the 4 physical buttons on the n\+RF52840-\/\+DK. It uses interrupts and semaphores to react to user input with low latency. 
\end{DoxyItemize}
