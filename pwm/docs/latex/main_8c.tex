\doxysubsection{Detailed Description}
System Entry Point and Orchestrator. 


\begin{DoxyItemize}
\item This module is responsible for the system initialization sequence\+:
\end{DoxyItemize}
\begin{DoxyEnumerate}
\item Initializes the Real-\/\+Time Database (RTDB) \mbox{[}Implicit\mbox{]}.
\item Initializes the Gantt Logger subsystem.
\item Spawns all worker threads in order of criticality.
\end{DoxyEnumerate}
\begin{DoxyItemize}
\item \begin{DoxyNote}{Note}
Architecture\+: The system follows a prioritized preemptive scheduling model compliant with Rate Monotonic Scheduling (RMS) principles. 
\end{DoxyNote}

\end{DoxyItemize}

Main Application Entry Point. 


\begin{DoxyItemize}
\item Configures the system and launches the Real-\/\+Time Operating System kernel. Never returns. 
\end{DoxyItemize}
\begin{DoxyItemize}
\item Launches the Critical Signal Generator Thread. Priority\+: 2 (Highest). Period\+: 100us (Hard Real-\/\+Time).
\item Launches the Input Handling Thread. Priority\+: 5. Event-\/driven (Interrupts).
\item Launches the UART Command Parser Thread. Priority\+: 7. Handles heavy string parsing without blocking Sig\+Gen.
\item Launches the LED Update Thread. Priority\+: 10 (Lowest). Visual feedback is non-\/critical.
